# Multi-Media Reached 25%

### 

## Javascript Code
```js
window.appEventData = window.appEventData || [];
appEventData.push({
  "event": "Multi-Media Reached 25%",
    "MultiMedia": {
        "MultiMediaName": "<MultiMediaName>",
        "MultiMediaType": "<MultiMediaType>"
    }
});
```
