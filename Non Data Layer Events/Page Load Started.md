## Variable Definitions

| Attribute Name|Data Source Type|Data Source|Description|
| --- | --- | --- | --- |
|Ad ID|Query String|ad_id|Provides the value of the ad\_id parameter if it is present in the URL, i.e, the Unique ID to identify an ad within the google ecosystem. Value is numeric, i.e., 624474936640, 624524716547, 647764849818|
|Adobe Experience Cloud ID|Custom Code|getMarketingCloudVisitorID();
return mcid;|Captures the Adobe Experience Cloud ID associated with user activity|
|AliasID|Query String|alias|Unique identifier of a customer.  Any id's considered PII must be hashed.|
|Campaign Tracking (s.campaign)|Query String|cid|CID code\/Campaign ID from URL query parameter. Value is alphanumeric or numeric.  0 or NULL values means organic traffic. E.g. svc1121v233043, Vanity20080, inv1839350130, statement|
|Google Click ID|Query String|gclid|Captures the value of the gclid parameter when present, I.e., the click ID from the traffic generated by a google ad. Value is alphanumeric & can contain special characters. E.g. |Google Click Source|Query String|gclsrc|Captures the value of the gclsrc parameter from URL, .i.e, the source platform of the ad URL generated by google. Value is alphanumeric & can contain special characters. E.g. aw.ds, 3p.ds, ds|
|Google Sitelink ID|Query String|ext_id|Provides the value of the ext\_id parameter if it is present in the URL, i.e, the Unique ID to identify an ad within the google ecosystem.|
